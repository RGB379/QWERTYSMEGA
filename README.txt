ANDROID VERSION
================
Это мобильная версия сайта Rick's Lab.

ВАЖНО:
Все пути используют ./ и работают относительно index.html.
Не открывайте только index.html из отдельной папки без остальных файлов.

Структура:
index.html
style.css
script.js
downloads/
  RickMortyPixel_0.2.1_Godot4.zip
  RickMortyPixel_Project.zip

Для GitHub Pages загрузите ВСЮ папку целиком в репозиторий.

Если сайт открыт как локальный file:// через файловый менеджер, используй downloads.html или прямые ссылки на ZIP. На GitHub Pages обычные ссылки работают как скачивание/открытие ZIP.
